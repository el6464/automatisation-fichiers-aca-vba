# Fonctionnement

La macro permet d'automatiser l'importation de données provenant d'un fichier ACA externe.

## Étapes

1. Sélection du fichier source.
2. Ouverture du fichier.
3. Lecture de la feuille `Formulaire`.
4. Identification des lignes contenant des données.
5. Copie des données.
6. Ajout dans le fichier de résultat.
7. Fermeture du fichier source.

## Objectif

L'objectif est de limiter les manipulations manuelles et de sécuriser le processus de consolidation des données.

## Confidentialité

Les fichiers ACA utilisés dans le cadre professionnel ne sont pas publiés dans ce dépôt.

Le code présenté est une version partageable permettant de documenter la démarche technique.
